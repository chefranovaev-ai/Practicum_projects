# qa-manual-projects
## Проект 1. Тестирование мобильного приложения «Яндекс Метро»
Провела функциональное и регрессионное тестирование новой сборки Android-приложения после рефакторинга, что измеряется 69 проверками в чек-листах и найденными дефектами с разбивкой по приоритетам.

### Что сделано:
Составила чек-лист функциональных проверок по требованиям, затронутым рефакторингом, с декомпозицией через mind-карту.
Подготовила регрессионный чек-лист с учётом специфики мобильного приложения: переключение сетей, геолокация, авиарежим, прерывания, смена ориентации, энергосбережение, обновление.
Протестировала приложение на эмуляторе Android Studio, сняла логи через Logcat.
Завела баг-репорты в Google Таблице с описанием шагов, ожидаемого и фактического результата.
Подготовила итоговый отчёт с разбивкой багов по приоритетам и рекомендациями для команды.

## Проект 2. Тестирование API Яндекс.Прилавок
Спроектировала и выполнила тестирование новой функциональности API Яндекс.Прилавка через Postman, что измеряется чек-листом из 5 блоков (наборы, курьерская доставка, корзина) и заведёнными баг-репортами, и позволило выявить дефекты до релиза.

### Что сделано
Проанализировала требования к бэкенду и документацию в Apidoc.
Составила чек-лист, покрывающий три эндпоинта: работа с наборами (POST /api/v1/kits/{id}/products), расчёт доставки (POST /fast-delivery/v3.1.1/calculate-delivery.xml), управление корзиной (GET, PUT, DELETE /api/v1/orders/:id).
Протестировала API через Postman: проверяла коды ответов, структуру JSON и XML, валидацию полей, обработку ошибок.
Завела баг-репорты в Google Таблице.
Подготовила отчёт о тестировании с оценкой статуса протестированной части продукта.
### Тестовое окружение
| Параметр |	Значение |
|----------|------------|
| Тестовый стенд |	https://{id}.serverhub.praktikum-services.ru |
| Документация |	Apidoc |
| Инструмент | тестирования	Postman |
### Инструменты
Postman · Apidoc · Google Sheets

## Тестирование веб- и мобильного приложения «Яндекс.Самокат»
Спроектировала тестовую документацию и провела ручное тестирование веб-версии «Яндекс.Самокат», а также составила тест-кейсы для мобильного приложения по макетам Figma, обеспечило покрытие ключевых пользовательских сценариев до передачи функциональности в автоматизацию.

### Задачи проекта
+ #### Задание 1. Тестирование веб-приложения
Изучила требования к веб-приложению и макеты в Figma.
Cоставила проверки по требованиям к экрану "Статус заказа".
Заполнила таблицу валидации полей экрана "Сделать заказ" с тестовыми данными.
Провела проверки по чек-листам, таблицам валидации и остальным макетам (кроме лендинга). Дефекты, найденные вне тестовой документации, зафиксированы отдельно.
Заведены баг-репорты для всех проверок со статусом FAILED.
+ #### Задание 2. Проектирование тестов для мобильного приложения
Изучила требования к мобильному приложению.
Составила тест-кейсы на функциональность, выделенную в требованиях жирным шрифтом и на вёрстку по макетам в Figma.

### Использованные инструменты
